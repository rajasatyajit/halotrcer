  --set tokvera.scan.target=http://<service>.<namespace>.svc.cluster.local:8000/v1 \
  --set tokvera.scan.confirm=true
  scan.confirm=true says you have read the load plan (tokvera scan --target ... --dry-run):
  the CronJob sends load to the target on every run.

Sievant (the MCP security gateway):
  --set sievant.enabled=true \
  --set-file sievant.gateway.config.inline=sievant.yaml
  (or --set sievant.gateway.config.existingSecret=<secret holding sievant.yaml>)

Each chart's own values.yaml and documentation describe every other setting;
put them under tokvera: and sievant:.
